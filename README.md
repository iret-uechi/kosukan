# kosukan（工数管）

FY26 上期（2026年4月〜9月）の個人工数 予実管理ツール。

計画工数（人月）に対して日々の作業実績をマイクロに記録し、カテゴリ別の消化率をリアルタイムで可視化する。

## セットアップ

```bash
git clone git@github.com:<your-username>/kosukan.git
cd kosukan
npm install
cp .env.example .env.local  # 必要に応じてスプレッドシートURLを設定
```

## 起動

```bash
npm run dev
```

ブラウザで http://localhost:5173 を開く。

## 使い方

### 日次入力タブ

日々の作業実績を記録する。

1. 日付を選択（◀▶ ボタンまたはカレンダー）
2. 各グループヘッダー右の **「+」ボタン** をクリック
3. カテゴリを選択するとエントリが追加される
4. **時間（h）** を入力（0.25h＝15分刻み）
5. **作業メモ**（Markdown対応）に作業内容を記録

- 同じカテゴリに複数エントリを追加可能
- 時間を0にするとエントリが自動削除される
- 入力は即時保存（localStorage + `data/workload.csv`）

### 予実サマリータブ

計画 vs 実績を人月単位で可視化。

- グループ別の消化率・残工数をプログレスバーで表示
- 月別フィルタ（上期全体 / 各月）
- 運用保守はサービス別の内訳を展開表示
- 月別棒グラフで実績推移を確認

### 履歴タブ

入力済みの日付を降順で一覧表示。

- 各日のカテゴリ内訳とメモ（Markdownレンダリング）を確認
- 「編集」で日次入力タブに遷移、「削除」でその日のデータを全削除

### 設定タブ

- **計画工数の編集**: グループ別の人月配分を変更
- **工数割振り根拠**: マスターデータへのリンク（`.env.local` で設定）
- **CSVエクスポート / インポート**: データのバックアップ・復元
- **全データリセット**

## データ保存

入力データは2箇所に保存される:

| 保存先 | ファイル | 用途 |
|--------|----------|------|
| ファイル | `data/workload.csv` | 実績データ（`.gitignore` 対象） |
| ファイル | `data/plans.json` | 計画値（`.gitignore` 対象） |
| ブラウザ | localStorage | フォールバック |

`data/workload.csv` と `data/plans.json` はユーザー固有データのため `.gitignore` に含まれている。フォーマットは `data/workload.sample.csv` を参照。

### CSVフォーマット

RFC 4180準拠。BOM付きUTF-8、CRLF改行。Google スプレッドシートや Excel にそのままインポート可能。

| カラム | 型 | 説明 |
|--------|----|------|
| 日付 | string | YYYY-MM-DD |
| カテゴリID | string | 内部識別子 |
| カテゴリ名 | string | 表示名 |
| グループID | string | 計画グループの識別子 |
| グループ名 | string | 計画グループの表示名 |
| 時間(h) | number | 入力値 |
| 人日 | number | 時間÷8 |
| 人月 | number | 人日÷20 |
| メモ | string | Markdown対応、改行可 |

## 計画グループ（合計 6.00 人月）

| グループ | 計画（人月） |
|----------|-------------|
| AMS課題対応 | 2.50 |
| External Monitoring | 1.00 |
| 各種EOL対応 | 0.75 |
| メール通知引継 | 0.25 |
| 運用保守 | 1.50 |

運用保守のサブカテゴリ: Abuse傾向検知 / AMS / メール通知システム / External Monitoring / MTG（定例・会議） / その他

計画外カテゴリ: 間接業務 / 有休

## 技術スタック

- React 18 + TypeScript + Vite
- データ永続化: localStorage + CSV（Vite dev server API）
- スタイリング: インラインスタイル（Tailwind不使用）
- 外部UIライブラリ不使用

## 換算

```
1人月 = 20人日 = 160h
```
